# UI起動ナビ

## やること

`docs/ui-startup-navi.md` を読み、**そこに書かれた手順をステップ0から全文そのまま提示する**。

## 禁止事項（いずれも 2026-08-15 の実地の失敗に基づく）

1. **その場で手順を組み立てない。** 記憶で書き直すと、毎回違う手順になり同じ失敗を繰り返す。
2. **要約・省略しない。** 「前回と同じです」「ステップ2から」で済ませない。
   マスターがどの状態から始めるかは分からないので、必ずステップ0から出す。
3. **移動を伴う手順で、移動するコマンドを省かない。**
   「リポジトリのフォルダで」とだけ書いた結果、マスターが `C:\Users\user` で実行して
   `ERR_CONNECTION_REFUSED` になった。パスを探して移動するところまでコマンドに含める。
4. **出力を見る前に原因を言わない。** 同日、原因を確かめずに対処を2回続けて指示して外し、
   信頼を損ねた。症状が説明できないうちは対処を提案せず、まず観測できる形にする。

## 失敗の報告を受けたとき

`docs/ui-startup-navi.md` の「うまくいかないときに AI へ渡すもの」の節に従い、**ターミナルの出力をそのまま貼ってもらう**。
出力を得るまで原因を断定しない。要約された報告だけで動かない。

## 手順を変えるとき

`docs/ui-startup-navi.md` を更新し、**変更点をマスターへ明示的に伝える**。黙って変えない。
