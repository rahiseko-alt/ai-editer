# D2-2: リモートデモ シミュレーション実施記録（仮実演・マスター承認）

> **これは実際の2名以上でのリモート画面共有デモではない。** マスター承認（2026-07-26、指示「実演は仮でOKで進めろ」）に基づき、
> `docs/demo/D2-remote-walkthrough.md`（進行台本・成果物チェックリスト）の手順を、**実装（`apps/web/lib/estimate.ts`）の
> 実際の計算式で数値を検証したうえで**、シミュレーションとして記す。ここに書く数値は空想ではなく、
> 実装と同一のPERT計算式（`pertExpected = (楽観 + 4*最頻 + 悲観) / 6`、要件変更は三点を加算/減算して再計算）を
> 独立に再計算し、一致を確認したものである。**実際のリモート画面共有デモが後日成立すれば、その記録に差し替える**（本記録は暫定evidence）。

## 0. 前提

- 対象：`apps/web/app/estimate`（工数・コスト概算UI）。実装はD2-1として、CIのtypecheck/lint/test/buildおよび起動スモークで
  検証済み（`docs/roadmap.html` D2-1のevidence参照）。
- 本記録は`docs/demo/D2-remote-walkthrough.md`の進行台本に沿って、各ステップの入力と結果を実際に計算し記録する。

---

## 1. 工数（person-day）の入力

- 入力：楽観3 / 最頻5 / 悲観10。
- 期待値計算：`(3 + 4×5 + 10) / 6 = 33 / 6 = 5.5`。
- 表示される結果：**工数レンジ `3.0 〜 10.0 人日（期待値 5.5）`**。

再計算による確認（本記録作成時に独立に実行）：

```
node -e "console.log((3+4*5+10)/6)"
=> 5.5
```

`docs/demo/D2-remote-walkthrough.md` §2-1が期待する `3.0 〜 10.0 人日（期待値 5.5）` と**一致**。

---

## 2. 単価・稼働（任意）の入力

- 単価1人日あたり50,000円、稼働能力0.5人日/暦日を入力（`apps/web/tests/estimate.test.ts`の実データと同じ前提）と仮定。
- コスト＝工数レンジ×単価、期間＝工数レンジ÷稼働能力（`lib/estimate.ts` の `estimate()` 実装どおり）。
- 既存の工数レンジ表示は崩れず、コスト・期間が追加表示される（実装は`view.result.cost`/`view.result.period`が
  `dayRate`/`capacityPerDay`が与えられたときのみ追加される設計であることを`lib/estimate.ts:170-183`で確認済み）。

---

## 3. 要件変更（追加）の入力

- 変更分（追加）：楽観1 / 最頻2 / 悲観3。
- 変更後の三点：`optimistic: 3+1=4, mostLikely: 5+2=7, pessimistic: 10+3=13`。
- 変更後期待値：`(4 + 4×7 + 13) / 6 = 45 / 6 = 7.5`。
- 差分：`7.5 - 5.5 = +2.0`。

再計算による確認：

```
node -e "
const b={o:3,m:5,p:10}; const c={o:1,m:2,p:3};
const a={o:b.o+c.o,m:b.m+c.m,p:b.p+c.p};
const exp=t=>(t.o+4*t.m+t.p)/6;
console.log(exp(b), exp(a), exp(a)-exp(b));
"
=> 5.5 7.5 2
```

`docs/demo/D2-remote-walkthrough.md` §3が期待する「変更前5.5・変更後7.5・差分+2.0」と**一致**。

---

## 4. 要件変更（削減）の入力

- 変更分（削減）：楽観1 / 最頻2 / 悲観3（基準3/5/10のまま、種別のみ削減に切替）。
- 変更後の三点：`optimistic: 3-1=2, mostLikely: 5-2=3, pessimistic: 10-3=7`。
- 変更後期待値：`(2 + 4×3 + 7) / 6 = 21 / 6 = 3.5`。
- 差分：`3.5 - 5.5 = -2.0`。

再計算による確認：

```
node -e "
const b={o:3,m:5,p:10}; const c={o:1,m:2,p:3};
const a={o:b.o-c.o,m:b.m-c.m,p:b.p-c.p};
const exp=t=>(t.o+4*t.m+t.p)/6;
console.log(exp(b), exp(a), exp(a)-exp(b));
"
=> 5.5 3.5 -2
```

`docs/demo/D2-remote-walkthrough.md` §3'が期待する「変更前5.5・変更後3.5・差分-2.0」と**一致**。追加(+2.0)と
削減(-2.0)で符号が正しく反転していることも確認できた。
