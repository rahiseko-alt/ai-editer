# kosespark video-shorts 仕組み表

> 作成 2026-06-20 / マスター確定の方向（CLAUDE.md §4）を1枚に。
> 到達ゴール=動画→縦型ショート→Instagram/X/ブログ自動投稿。運営コスト≒0（計算は客PCに寄せる）。

## 1. 全体の流れ（パイプライン段階）

| # | 段階 | 担当（誰/何のツール） | 入力 → 出力 | 種別 | 現状 |
|---|------|----------------------|-------------|------|------|
| 1 | 素材受け取り | マスター（ギガファイル便等で渡す） | 動画 → input/ | 入口のみ | 稼働 |
| 2 | 文字起こし | **faster-whisper**（外部の音声認識AI） | mp4 → transcript.json（単語＋秒） | 外部AI | 稼働 |
| 3 | 区間選定の指示書 | select-segments.mjs | transcript → llm-request.md | 自動 | 稼働 |
| 4 | 区間を選ぶ（頭脳） | **Claude（あなたの裏で動く）** | llm-request → llm-response.json（残す台詞＋hook） | AI判断 | 稼働 |
| 5 | 秒数を確定 | reverse-match.mjs（台詞を文字起こしに逆照合） | keepText → start/end秒 | 自動 | 稼働 |
| 6 | 字幕生成（任意） | srt-builder.mjs → ASS字幕 | 区間 → .ass | 自動・**字幕有無は毎回確認** | 稼働 |
| 7 | 縦化＋カット＋焼き込み | **ffmpeg** | mp4＋区間＋字幕 → 9:16ショート | 外部ツール | 稼働 |
| 8 | エフェクト（任意） | apply-effect.mjs（ffmpeg）/ 将来Remotion | ショート → 派手版 | 外部ツール | ffmpeg稼働 |
| 9 | 選別 | UI or チャット | candidates.json → 採用分 | 手動 | 稼働 |
| 10 | SNS投稿 | Instagram/X/ブログ API | 採用ショート → 各SNS | 外部API | **未着手** |

## 2. 将来の層アーキテクチャ（客PC内で動くローカルWebアプリ）

| 層 | 中身 | どこで動く | コスト |
|----|------|-----------|--------|
| 画面 | Web編集UI（字幕ON/OFF・エフェクト種類＋時間・カット追加・文字起こし表示） | 客PCの localhost | 0 |
| 橋 | ローカルAPIサーバ（Node・UI⇄エンジン仲介） | 客PC | 0 |
| エンジン | whisper / ffmpeg /（将来）Remotion / reverse-match | 客PC | 0 |
| 頭脳 | Claude（区間選定・編集判断） | 客の Claude Code | サブスク内・追加0 |
| 保存 | ローカル or Cloudflare R2 | 客PC / R2無料枠 | 0〜 |
| 配信 | Instagram(Reels)/X/ブログ API | 各SNS | 下表参照 |

> 注: 客PCローカルアプリのUIは localhost 配信が自然。独自ドメイン配信→localhost は mixed-content で詰まるためブランドはUI内で表現。

## 3. コスト内訳（運営コスト≒0 の根拠と"穴"）

| 項目 | コスト | 備考 |
|------|--------|------|
| 計算（whisper/ffmpeg/Remotion） | **0** | 客PCで実行＝サーバー代不要。これが0化の肝 |
| Webホスティング | **0** | localhost or Cloudflare Pages無料 |
| ストレージ | **0〜** | ローカル0 / R2は10GB無料・転送無料 |
| AI頭脳（Claude） | **追加0** | 既存サブスク内 |
| Instagram API | **0** | ただし動画の公開URLホスト必須・ビジネスアカウント・審査 |
| ブログ API | **0** | WordPress/Ghost等の自前ブログ |
| **X API** | **⚠ 有料の穴** | 無料枠は投稿制限きつい・TOS変動。実運用 Basic $100/月〜（要検証） |
| ギガファイル便 | 0 | 素材を渡す入口のみ。**DB/恒久保存には不可**（数日〜100日で消滅・API無し） |

## 4. コンセプト整合（CLAUDE.md §0「外部AIを束ねる」）

| 工程 | 性格 | コンセプト適合 |
|------|------|---------------|
| 文字起こし | 外部AI（faster-whisper）を使う | ◯ 束ねている |
| 区間選定 | Claude（頭脳）＝ハブ役 | ◯ Genspark型の中核 |
| 縦化/字幕焼き | ffmpeg（道具・非AI） | ◯ 実行ツール |
| 凝った字幕/エフェクト | Remotion=自作 / 外部字幕AI=束ねる | △ 分岐。判断軸＝"外注すべき専門AI仕事か自作か" |
