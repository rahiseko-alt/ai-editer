# AI-Editer video-shorts 利用条件・免責（客向け・素案）

> ⚠ **たたき台（要マスター確定＋必要なら専門家レビュー）**。本書は法的性質を持つため、文言はマスターが確定し、契約・課金・免責の条項は必要に応じて専門家の確認を得る。素案は「何を取り決めるべきか」の骨子を示すもの。

## 1. 提供物と役務範囲

- 提供物: 客の PC 上で動作する動画編集ツール `video-shorts`（長編動画→縦型/横型ショート自動生成）。
- AI-Editer の役務: **構築・設定・保守の代行**。ツールは客の PC 上でローカル動作し、AI-Editer のサーバ・アカウントを介さない。

## 2. 費用と課金

- ツール本体の対価: 構築・設定・保守の役務費（別途見積）。
- **外部 API 課金は客負担**: 文字起こしを Groq で高速化する場合、客自身の Groq アカウントの従量課金（無料枠超過分）は客が負担する。既定はローカル whisper（無料）で動作する。
- LLM（区間選定/digest）は客の Claude サブスクリプションを利用し、追加の従量課金は既定で発生しない。

## 3. データの取扱い

- 客の動画・音声・文字起こしは **客の PC 上でのみ処理**され、AI-Editer は保存・複製・外部送信しない。
- Groq を使う場合、音声は客の鍵で Groq API に送信される（客と Groq 間の取扱いは Groq の規約に従う）。

## 4. 無保証範囲（要マスター確定）

> 以下は素案。ツールの性質上、以下は品質保証の対象外とする方向。

- 文字起こし精度（whisper/Groq turbo の誤変換）。用語辞書で補正可能だが完全ではない。
- LLM の区間選定・digest の内容品質（素材の面白さに依存し、一定スコアを保証しない）。
- 出力画質（元素材の解像度が上限。低解像度素材は精細化できない）。
- 処理速度（ローカル文字起こしは CPU 律速）。

## 5. 責任制限（要マスター確定）

- 鍵管理: `key-management-policy.md` の通り、鍵は客所有・課金は客負担。AI-Editer は鍵を預からない。
- AI-Editer の責任は役務（構築・設定・保守）の範囲に限る。客の鍵・アカウントで生じた課金・データ事故について、AI-Editer は原則責任を負わない（最終文言はマスター確定）。
