# E1-b: 差し替え適用サンプル2 ─ BtoB SaaS営業チームの成約率改善

> ロードマップ葉 **E1-b** の成果物。**B3（`docs/design/B3-blank-template.md`）の空欄テンプレを、
> E1-a（個人経営パン屋・小売の物理在庫問題）とは**質的に異なる**2つ目の課題「BtoB SaaS営業チームの
> 成約率改善」（無形サービス・知識労働・在庫を持たない）で埋め、差し替えだけで12コマの骨格が
> 破綻なく成立することを示す。**
>
> - E1-a との質的な違い：業種（小売の食品廃棄 → BtoB SaaS営業）、対象（1店舗のオペレーション →
>   複数人の営業チームの商談プロセス）、成果物の性質（物理的な陳列・発注オペレーション →
>   商談スクリプト・提案資料・CRM運用という無形の知識労働プロセス）。
> - 骨格の正は **B1**。変更管理の正は **B2**。本書はロードマップ本編（`docs/roadmap.html`）の代わりにはならない。

## §A 案件ヘッダー

| 項目 | 記入内容 |
|---|---|
| 課題名 | BtoB SaaS営業チーム（5名）の商談成約率改善 |
| 顧客/対象 | 営業マネージャー（プロセス変更の権限者）、営業担当5名 |
| 最優先イシュー | 商談化（初回アポ）後の成約率が低く、案件が中間フェーズで失注・停滞している |

| 変更の扱い | B2 の再凍結イベントに従う（本書 §C に起票欄あり） |

## 結論

E1-aとは業種・対象・成果物の性質が質的に異なる「BtoB SaaS営業チームの成約率改善」でも、B3のテンプレを
差し替えるだけで目的列（骨格）を変更せずに12コマ全てが具体化でき、破綻しなかった。これにより E1
（質的に異なる2課題での差し替え成立）の受入が完了する。
