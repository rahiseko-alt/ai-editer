# C-10-1: コマ10 教材 ─ 増分5〜6の受入と仕上げ発注（進行台本＋発注書テンプレート）

> ロードマップ葉 **C-10-1** の成果物。コマ10（60分）の進行台本。残る増分（5〜6）の独立受入（コマ4型）と、
> 閾値到達を確認したうえで仕上げ作業を発注する手順（コマ3型）をまとめる。
>
> **本書で満たす範囲**：コマ10のスライド構成・進行台本・仕上げ発注書テンプレートが準備されていること。
> **まだ満たさない範囲**：実セッションで閾値到達の実測提示と仕上げ発注が実際に行われた記録（**C-10-2** が正）。

## 0. コマ10の到達点（B1コマ10行より）

解決ロードマップの葉が閾値到達したことが実測で示され、仕上げの開発指示が受け渡されている。

## 2. スライド構成

1. **今日のゴール**：残る増分を受け入れ、ゴールにどこまで近づいたかを数字で示し、最後の仕上げを発注する回。
2. **独立受入（該当増分があれば）**：コマ4と同じ手順。
3. **閾値到達の確認**：コマ9の再測定と比較し、どこまで近づいたかを示す。
4. **仕上げ発注（コマ3と同じ型）**：残る差分を埋める最後の打ち手を発注する。

---

## 3. 進行台本

### 0-10分：目的の確認

```text
今日は残っている増分を受け入れ、ゴールまでの距離を数字で確認したうえで、最後の仕上げを発注します。
```

### 10-25分：増分5〜6の独立受入（該当があれば、コマ4と同じ手順）

- 受入条件を読み上げる → 再現手順で確認 → 合否記録。

### 25-40分：閾値到達の確認

- コマ9の実測値と比較し、目標値までの残り幅を提示する。
- 「閾値」は事前に合意した水準（例：目標値の90%到達等）を指す。全達成でなくてよい（仕上げが別にあるため）。

### 40-55分：仕上げ発注（コマ3と同じ型）

- 残る差分を埋めるための最後の打ち手を、受入条件・期限・見積り（幅＋信頼度）つきで発注する。

### 55-60分：承認

**承認の問い**

```text
この実測結果と仕上げ発注の内容を確定してよいですか。
```
