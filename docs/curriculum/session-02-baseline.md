> ロードマップ葉 **C-2-1** の成果物。コマ2（60分）の進行台本と、最優先イシューのベースライン実測値・
> 目標値（定義100%）を測定方法つきで確定するためのワークシートをまとめる。
>
> **本書で満たす範囲**：コマ2のスライド構成・進行台本・測定ワークシートが準備されていること。
> **まだ満たさない範囲**：実セッションでベースラインが実際に確定した記録（**C-2-2** が正）。

## 0. コマ2の到達点（B1コマ2行より）

最優先イシューのベースライン実測値と目標値（解決の定義100%）が、測定方法つきで確定している。

## 2. スライド構成

1. **今日のゴール**：最優先イシューを「測れる数字」にする回であること。
2. **測定方法を決める3条件**：①後から第三者が再現できる ②定期的に取れる ③イシューの実態を代表する。
3. **現状（ベースライン）を測る**：既存データがあるか／無ければ何を新たに測るかを確認する。
4. **目標値（定義100%）を決める**：顧客が「解決した」と認める閾値を数値で合意する。
5. **承認チェック**：実測値・目標値・測定方法の3点が揃っているか。

---

## 3. 進行台本

### 0-10分：目的の確認

```text
今日は最優先イシューを、後から誰が見ても同じ判定になる「数字」にする回です。
測定方法まで含めて決めるので、来週以降ずっとこの数字とやり方で進捗を測ります。
```

### 10-30分：測定方法を決める

- 既存データ（POS・CRM・業務ログ等）があるか確認する。無ければ、今日から取り始める方法を決める。
- 「この測定方法は来週以降も同じ手順で繰り返せますか」を確認する。

### 30-45分：ベースラインを測る

- 直近の実績（可能なら4週間分など複数回分）を確認し、平均・ばらつきを把握する。
- 一度きりの数字ではなく、幅（ばらつき）を含めて記録する。

### 45-55分：目標値（定義100%）を合意する

```text
「解決した」と言えるのは、この数字がどうなったときですか。
```

- 顧客の言葉で閾値を引き出し、数値化する。

### 55-60分：承認

**承認の問い**

```text
この実測値・目標値・測定方法を、以降の進捗判定の基準として固定してよいですか。
```

## 4. ベースライン票（ワークシート）

```text
最優先イシュー：＜コマ1で確定したイシュー＞
測定方法：＜手順・データ源・集計単位（日次/週次等）＞
ベースライン実測値：＜数値＋期間＋ばらつき＞
目標値（定義100%）：＜数値＋単位＋顧客が合意した閾値＞
```
