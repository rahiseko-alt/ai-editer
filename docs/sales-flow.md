# kosespark video-shorts 販売フロー（社内オペレーション）

> 顧問契約（AI顧問契約書 第10版）に基づき、引き合いから納品・保守までを回す手順書。
> 客に見せる同意事項＝`video-shorts/install/consent.html`（同契約 別紙4・別紙5 相当）。客の使い方＝`video-shorts/install/user-manual.html`。

## 使う書類・画面

| 書類/画面 | 用途 | 根拠条文 |
|---|---|---|
| AI顧問契約書 第10版（本体） | 顧問契約の本体 | 全体 |
| 別紙「業務の内容」 | 本業務の具体的実施方法 | 第2条 |
| 別紙A（UI独自部分・画像特定） | 成果物の権利帰属範囲 | 第7条 |
| 別紙B（プロトタイプ最終依頼書） | 無償プロトタイプの範囲 | 第8条 |
| 別紙D（受入基準確認書） | 検収の合否基準 | 第10条 |
| 別紙1（保守契約書） | 保守業務（任意・準委任） | 第12条 |
| 別紙2（競業）／別紙3（解約申請書） | 競業取決め／解約様式 | 第20条・第22条 |
| **install/consent.html**（＝別紙4・別紙5） | 外部サービス・AI利用の同意 | 第14条 |
| **同意の控え `consent-*.txt`** | 同意した事実・文言・日時の証拠 | 第14条 |

## フロー（段階順）

| # | 段階 | やること | 使う書類/画面 | 次へ進む条件 |
|---|---|---|---|---|
| 1 | 引き合い・ヒアリング | 客の課題・素材・PC環境（Node/Python/ffmpeg可否）を確認 | — | 課題と適合を確認 |
| 2 | 提案・見積 | 顧問料(月額)・構築費・実費(客負担)を提示 | 第3条 | 客が金額に合意 |
| 3 | 顧問契約締結 | 本体契約＋必要な別紙に記名押印 | 顧問契約書・別紙 | 甲乙双方が署名 |
| 4 | **同意取得** | 客が `install/consent.html` を開き同意→控えDL→**担当者が控えを受領・保管** | consent.html・控え | 控えを保管（第14条 別紙4/5） |
| 5 | 構築代行 | 客PCにセットアップ。Node/Python/ffmpeg・依存・（任意）Groq鍵は**客本人が入力** | user-manual.html | ローカルで1本生成できる |
| 6 | 検収 | 別紙Dの受入基準を成果物が再現できるか確認→合格 | 別紙D | 検収完了（第10条） |
| 7 | 保守開始（任意） | 別紙1「保守契約書」を締結 | 別紙1 | 保守料合意（第12条） |
| 8 | 継続・改修 | 使い心地の改善／新機能は別途見積・**有償**（承諾後着手） | 見積 | 都度書面合意（第11条5項） |

## 料金の型

| 費目 | 内容 | 根拠 |
|---|---|---|
| 顧問料 | 月額（暦月・途中は日割り） | 第3条1項・4項 |
| 構築費 | 着手後は返金なし | 第8条・運用 |
| 実費（AI利用料） | **客負担・客名義**（Groq等） | 第3条3項 |
| 保守料 | 別紙1による | 第12条5項 |

## 鍵の扱い（必ず守る）

- API キーは**客名義・客本人が入力**。kosespark は**預からない・保存しない**（第3条3項／同意画面3項）。
- 鍵をチャット・メール・スクショに貼らせない。代行時も入力箇所は客に伏せる。

## 各段の完了チェック（この順で潰す）

1. [ ] ヒアリングで PC 環境（ffmpeg/Node/Python）が満たせると確認した
2. [ ] 見積金額に客が合意した
3. [ ] 顧問契約書＋必要な別紙に双方署名した
4. [ ] **客が同意し、控え `consent-*.txt` を受領・保管した**
5. [ ] 客PCでローカル1本を生成できた（鍵は客が入力）
6. [ ] 別紙Dの受入基準を再現し検収完了した
7. [ ] （任意）保守契約（別紙1）を締結した
