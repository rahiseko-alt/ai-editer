# kosespark 記録 — claude -p 区間選定タイムアウトの根治（失敗→修正 全履歴）

日付: 2026-06-23
対象: `video-shorts/server/claude-select.mjs`（区間選定エンジン・サーバー/Web UI 経路）
状態: コード修正完了・**実動画 12h での全チャンク完走は未実行【未実行】**。最小プロンプトでの根治は実証済み【実行済み】。

---

## 0. 結論（先に要点）

- **真因**: `claude -p` をチャンクごとに spawn するたび、子プロセスが MCP サーバー（serena 等）を毎回ブートしていた。serena の activate/index だけで 150s+ かかり、**入力サイズに関係なく**起動コストが 300s タイムアウトを食い潰していた。
- **直し**: spawn 引数に `--strict-mcp-config` を追加し MCP をゼロ化。300s タイムアウト → **5.5s**（実測・約 55 倍）。**モデルは変えず選定品質は不変**。OAuth サブスクログインも維持。
- **捨てた案**: `--bare`（MCP/hook を全スキップして更に軽いが、OAuth ログインまで剥がし `Not logged in` になる＝無料運用が壊れるため不採用）。

## 2. 最終的に入れた変更（`server/claude-select.mjs`）

1. **構造**: 「全文 1 回渡し」→「transcript を chunk 分割し各 chunk を個別 `claude -p` で選定 → プール並列 → 成功分を統合（一部失敗は継続・全滅時のみ throw）」。`chunkSegments` / `buildPrompt` を import、`runOneChunk` / `runPool` を新設。
2. **chunk サイズ**: `chunkSegments(transcript, 10 * 60, 60)`（10 分尺・overlap 60s）。
3. **起動軽量化（本命の直し）**: spawn を `claude -p --strict-mcp-config --output-format json` に。MCP サーバーをゼロ化。
4. コメントに真因と `--bare` 不採用理由を明記（再発時の判断ショートカット）。

検証: `node --check server/claude-select.mjs` PASS。最小プロンプト往復 5.5s・ログイン維持・正常 JSON。

## 3. 教訓（理由つき・次セッション/他プロダクトでも効く）

1. **`claude -p` をサブプロセスで多数回叩く設計では、起動の重し（MCP/hook/CLAUDE.md ロード）が支配的コストになる。** 入力が小さくても遅いなら、まず起動コストを疑え。MCP を切るだけで桁が変わる。
2. **MCP を切るなら `--strict-mcp-config`（--mcp-config 未指定）を使う。`--bare` は OAuth ログインも剥がすので無料サブスク運用には使えない。** この区別が今回の肝。
3. **「サイズが律速」という直感は必ず実測で検証する。** 半分に縮めて改善しないなら、その仮説は棄却して別の律速要因（起動・モデル）に切り替える。1 変数ずつ動かして切り分けた。
4. **CLI フラグは記憶やドキュメントだけで本番に書かず、`claude --help` で実機の実在を裏取りしてから書く。**

## 4. 残課題 / 次の一手

1. **【未実行・最優先】** 実動画（できれば 12h 級）を Web UI から投入し、**全チャンクがタイムアウトせず完走するか**を実機確認する。最小プロンプトの 5.5s は起動コスト消滅の証拠だが、実チャンクの推論時間込みの完走は未確認。
2. **【任意レバー】** さらに速度/負荷を下げたいなら `--model haiku` 指定。区間選定は要約抽出寄りのタスクで haiku でも実用的だが、**選定品質が変わるため採用は要マスター判断**。
3. **【観測】** 単発テストで `total_cost_usd: 0.226`・`claude-opus-4-8` 表示。サブスク OAuth では実課金されない設計前提（CLAUDE.md）だが、コスト最小化したい場合は haiku が効く。
4. **【横断・別経路】** CLI 単体 `pipeline.mjs` は `claude -p` を直接 spawn していない（別経路）ため本修正の対象外。Web UI/サーバー経路は `pipeline-runner.mjs → runClaudeSelect`（本ファイル）に集約済みで完全カバー。
