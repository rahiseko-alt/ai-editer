### 唯一の未修正バグ（本物・実ログで確認済み）
`server/claude-select.mjs` の `claude -p` が、区間選定 JSON でなく **「承認をお待ちしています」というテキストを返す**ことがあり、`parseResponse` が失敗する（e2e 実ログで `parseResponse 失敗: Unexpected token '承', "承認をお待ちしていま"...` を確認）。原因＝headless の claude がツール承認／plan 待ちに入る。

**修正方法（明確）**: `server/claude-select.mjs` の spawn 引数（現状 `["-p", "--output-format", "json"]`）に **`--permission-mode bypassPermissions`** を追加する（または `--disallowed-tools` で全ツール禁止）。claude CLI に `--permission-mode <bypassPermissions等>` / `--allowed-tools` / `--disallowed-tools` が実在するのは `claude --help` で確認済み。区間選定は stdin のテキストを読んで JSON を返すだけ＝ツール不要なので、承認ゲートを無効化すれば安定する。プロンプト側にも「承認・確認は不要、JSONのみ即返せ」を足すと堅い。
