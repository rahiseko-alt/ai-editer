## 2026-06-23 第2セッション — race condition バグ修正

### やったこと

- **バグ特定**: 「編集できませんでした：処理に失敗しました」の根本原因 = race condition
  - `POST /api/jobs` → 202即返し → 非同期でパイプライン開始
  - python 等の spawn が即座に失敗すると `broadcast(..., "error")` が購読者ゼロの状態で発火 → 誰にも届かない
  - その後クライアントが EventSource 接続 → サーバーから沈黙 → ブラウザが接続エラーと判定 → `ev.data=undefined` → デフォルトメッセージ「処理に失敗しました」が表示
- **修正**: `subscribeJob` に接続時リプレイロジックを追加（既に done/error 状態ならその場で通知 + close）
- **指摘対応**: code-reviewer 指摘の done ブランチ `close()` 漏れも修正済み
- **ファイル**: `video-shorts/server/pipeline-runner.mjs`（255行）
