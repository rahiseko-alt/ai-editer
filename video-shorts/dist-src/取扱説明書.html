動画編集キット 取扱説明書

Claude のデスクトップアプリで、チャットに動画を渡すだけで要点をつないだダイジェスト動画を作ります（Windows 用）。

用意するもの

  • Windows の PC
  • Claude の有料プランのアカウント
  • Groq のアカウント（無料・おすすめ。文字起こしが速くなります）

はじめての準備（最初の1回だけ）

  1. Claude のデスクトップアプリを入れてログインする（claude.ai/download）。
  2. キットをダウンロードする：github.com/rahiseko-alt/ai-editor-kit を開き、緑の「Code」→「Download ZIP」。
    ZIP を右クリック →「すべて展開」し、できたフォルダを C:\ai-editor-kit のような短い英字の場所に置く。
  3. Claude のアプリで「Code」を選び、そのフォルダを開く。
  4. チャット欄に 使えるようにして と送る。
    必要なソフトは Claude が入れます。許可を求める画面が出たら「はい」を押してください。
  5. Claude に頼まれたら、Groq のキーを用意して貼り付ける（console.groq.com →「API Keys」→「Create API Key」）。

使い方（毎回）

① 動画を渡す動画をチャット欄にドラッグし この動画を編集して
② 台本案を読む残す所・捨てる所が出ます
③ 承認する承認／直したい所を言葉で伝える
④ 受け取る完成した動画の場所が届きます
  • 希望は一緒に書く：「縦型で」「字幕を付けて」「3分くらいに」など。書かなければ横型・字幕なし。
  • 承認するまで動画は作られません。元の動画は変わりません。
  • 完成した動画はキットのフォルダ内 .runtime\outputs\ に保存されます。

知っておいてほしいこと

  • Groq のキーを設定すると、文字起こしのため音声が Groq に送られます。文字起こしの文章は Claude が読みます。
  • AI は音を聴けません。つなぎ目に「プツッ」という音がないかは、一度ご自身の耳で確かめてください。
  • BGM・効果音・図を足すなど、素材に無いものを加える編集はできません。
困ったときは、起きたことをそのままチャット欄に書いてください（例：「エラーが出た」「止まったみたい」）。Claude が調べます。
