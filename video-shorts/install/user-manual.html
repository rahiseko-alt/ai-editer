video-shorts 使用説明書

長編の動画から「見どころショート」を自動で作るツールです。あなたの PC の中で動き、動画は外に送られません（高速文字起こしを使うときだけ、あなたの鍵で Groq に音声を送ります。また「ダイジェスト」モードでは、文字起こしのテキスト全文を台本作成のため Claude（Anthropic）へ常時自動で送信します。詳しくは4章・7章参照）。

0. 最初に（同意）

ご利用の前に、同じフォルダの consent.html を開き、外部サービス・AI利用の同意事項をご確認のうえ同意してください。同意すると「控え（同意の証拠）」がダウンロードされます。控えは保管してください。構築を代行でご依頼の場合は、担当者にお渡しください。

1. 用意するもの（初回のみ・無料）

ソフト用途入手先
Node.js 18 以上本体の実行nodejs.org（LTS 版）
Python 3.12文字起こしpython.org
ffmpeg / ffprobe動画処理ffmpeg.org

入れ終わったら、ターミナル（Windows は PowerShell）で次を打ち、バージョンが表示されれば準備完了です。

node -v
python --version
ffmpeg -version

2. 初回セットアップ

  1. 同意：consent.html を開いて同意（上記 0）。
  2. 文字起こしライブラリを入れる（無料）： 
    pip install -r requirements.txt
  3. （任意）高速文字起こしを使う場合だけ：あなたの Groq アカウントで鍵を作り、video-shorts/.env に1行だけ書きます。鍵はこのファイル以外に貼らないでください。 
    GROQ_API_KEY=gsk_（console.groq.com/keys で作成した鍵）
    鍵が有効か確認： 
    python src/check-groq-key.py

    鍵を設定しなくても、無効でも、ネットが切れても、自動で無料のローカル文字起こしに切り替わるので止まりません。

3. 使い方（動画 → ショート）

例として、作業名を myvideo とします。上から順に実行してください。

  1. ジョブを作る（動画ごとに作業フォルダを新規作成します。--mode・--sub・--orient は毎回必須です。意味は4章「モードの選び方」参照）： 
    node pipeline.mjs init 入力動画.mp4 --mode topic --sub off --orient 縦

    最後の行に work/入力動画-（ランダムな文字列） のような作業フォルダのパスが表示されます。以降の手順に出てくる work/myvideo は、この表示されたパスに読み替えてください。

  2. 文字起こし： 
    python src/transcribe.py 入力動画.mp4 work/myvideo/transcript.json
  3. 区間選定（AI が見どころを選ぶ）： 
    node pipeline.mjs select work/myvideo
  4. レンダリング（ショートを作る）： 
    node pipeline.mjs render work/myvideo
  5. 候補を確認：output/（作業フォルダ名）/ に short-01-....mp4 のような動画が並び、同じ場所の candidates.json に各候補の情報が記録されます。フォルダを開いて動画を実際に再生し、採用するものを選びます（ブラウザの選別画面は使いません）。

4. モードの選び方

選ぶもの意味
話題ごと（topic）話題の切れ目ごとに1本。全編をカバーしたい時
ダイジェスト（digest）面白い所だけを1本に凝縮。ハイライトが欲しい時（文字起こし全文を台本作成のため Claude（Anthropic）へ常時自動で送信します）
縦 / 横縦=SNS リール向け（1080×1920）／横=画面録画など細かい文字を残す用途（1920×1080）
字幕 ON / OFF字幕を焼き込むか。ONは誤変換に注意（用語辞書で補正可）

モード・縦横・字幕は毎回たずねられます（前回の設定は引き継ぎません）。

5. 候補の確認

ショートは「候補」として複数作られます。output/（作業フォルダ名）/ フォルダを開き、並んだ動画を実際に再生して、良いものだけを採用してください（ブラウザの選別画面は使いません）。すべてを自動採用にはせず、必ず目で見て選びます（見どころの歩留まりは 30〜50% が目安です）。

6. うまくいかない時

症状対処
ffmpeg not foundffmpeg を入れ直し、ffmpeg -version が出るか確認
文字起こしが遅いローカルは PC 性能に依存。速くするには Groq 鍵を設定（2-3）
Groq が [NG]鍵をコピーし直す／console.groq.com で作り直す。それでも無効なら鍵設定を消せば無料のローカルで動く
字幕の誤変換src/term-corrections.json に「誤→正」を追記すると次回から直る
候補が少ない/微妙歩留まり 30〜50% は仕様。ui で採用分だけ使う

7. よくある質問

動画は外部に送られますか？
動画そのものは外部に送られません。処理は PC 内で行われます。高速文字起こし（Groq）を使うときだけ、音声があなたの鍵で Groq に送られます。また、「ダイジェスト（digest）」モードでは、動画ではなく文字起こしのテキスト全文を、台本を組み立てるために Claude（Anthropic）へ常時自動で送信します（都度の確認はありません）。新しいサービスへの登録は不要で、あなたが使っている Claude Code の契約をそのまま利用するため、追加料金も基本的に発生しません。
お金はかかりますか？
ツールはローカルで無料動作します。Groq を使い無料枠を超えた分だけ、あなたの Groq アカウントに課金されます（鍵を設定しなければ無料）。
字幕の変換ミスが気になります。
用語辞書（src/term-corrections.json）に「誤→正」を登録すると、次回の文字起こしから直ります。
