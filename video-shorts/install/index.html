video-shorts のダウンロード

長編動画から縦型/横型ショートを自動生成するツールです。下のボタンからダウンロードできます。

▶ ダウンロード（video-shorts.zip）

ダウンロード → 利用開始の流れ

  1. 1上の「ダウンロード」を押す
  2. 2ダウンロードしたファイルを開く（展開する）
  3. 3展開したフォルダの中の start-here.md を Claude Code に渡し「このファイルを実行して」と伝える

    ここから先はチャットの会話で進みます。

  4. 4質問に答えながら進める（内容の同意 → 必要なソフトの導入 → 文字起こしの設定 → skill登録）

    1つずつ「はい／いいえ」で確認されます。分からない点は聞き返して大丈夫です。

  5. 5「準備完了です」と言われたら完了
  6. 6使える状態になる

    使用説明書に沿ってご利用ください。
