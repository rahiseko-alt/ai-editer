# 一般的な日本語の文の集まり（用語辞書の誤爆を測る土台）
#
# 【何のためのファイルか】用語辞書へ語を載せてよいかを、この素材に対して判定する。
# 直す前の語がこの素材に1回でも出てくるなら、それは「ふつうの日本語の語」なので載せない。
# 載せると、他の案件でその語が出るたびに書き換わってしまう。
# 出てこない語は誤変換で生まれた文字の並び（追患版・椎間盤 等）なので、そのまま載せて安全である。
#
# 【なぜ「その案件の書き起こし」で測ってはいけないか】2026-08-08 の失敗。
# 鍵を選んだのと同じ文の中で「当たるのが1箇所」を測っていたが、鍵はそうなるまで伸ばして
# 選ぶのだから、必ず1箇所になる。何も測っていなかった。受入事実は「まだ見ぬ他の案件が
# 壊れないこと」なので、判定の土台は鍵を選ぶのに使わない別の素材でなければならない。
#
# 【なぜ「前後の文字を足す」方式をやめたか】上の失敗を受けて一度は
# 「この素材に当たらなくなるまで前後の文字を足す」方式にしたが、足してできる鍵は
# 「高速です」「うは高速」「て行き」のような、ふつうの日本語なのに素材にたまたま無い並びになる。
# 素材を1.5倍にしても漏れ続けた。判定対象が「任意の部分文字列」だと、その空間は語の空間より
# 桁違いに広く、手で書ける規模の素材では偽の安全しか作れない。
# いまは判定対象を「直す前の語そのもの」に狭めてある。
#
# 【この素材が満たすこと（受入条件。中身を変えるときはこれを守る）】
#  1. すべての助詞（は・が・を・に・へ・と・で・から・より・まで・の・や・か・ね・よ・な）が
#     自然な文の中に現れる。
#  2. ていねい語の語尾（です・ます・ました・ません・でした・ですね・でしょう）が現れる。
#     用言の活用（する・した・している・される・できる）も現れる。
#  3. 形式名詞・接続詞（こと・もの・ところ・という・そして・しかし・なので・だけど・ため）が現れる。
#  4. 日常の複合語（高速道路・新幹線・携帯電話・会社員・駅前・今日・明日）が現れる。
#     とくに、誤変換の修正で巻き添えになりやすい一般的な2〜3文字の語を含む文脈を持つ。
#  5. 特定の案件の固有名詞・専門用語を含まない（含めると、その語を辞書へ載せられなくなる）。
#
# 行頭が # の行は判定に使わない（この説明を素材の一部として数えないため）。
# このファイルの SHA-256 は受入条件に凍結する。中身を変えたらハッシュも更新すること。
